Dataset selection: what each source is for

Scope: every human single-protein target (universal, reported per protein family). Decided by the team; see DECISIONS.md D-001.
Source (version)What it containsRole in TrustDTIUsed in (project week)Decision / why
ChEMBL 37
SQLite, 5.8 GB → 30 GB		24.5M curated bioactivity measurements, 2.9M compounds, 18.5k targets, from papers, patents and screening centres.Primary source. Drug–protein measurements that build Network 1 and train the model.W1–W7Selected Largest curated, openly licensed source. Records units, censoring, assay confidence and origin for every value.
BindingDB 202609
TSV, 0.6 GB → 9 GB		3.2M binding measurements (Ki, IC50, Kd, EC50) from literature, patents, PubChem.Cross-check and possible extra coverage.W1 checkReview Profiling showed it largely copies ChEMBL (and vice versa). Recommendation: ChEMBL-only for v1.
UniProt
Swiss-Prot 2025_03 via ChEMBL		Canonical protein IDs (accessions) and amino-acid sequences.Protein identity key across databases; sequences for ESM-2 embeddings.W3–W4Selected Standard protein identifier; already linked inside ChEMBL.
Open Targets / DisGeNETCurated gene/protein–disease associations with evidence scores.Disease anchor (Network 2): looked up, never predicted.W8Planned Curated and auditable. Keeps the disease link independent of the model.
PubMed / PubTator
NCBI E-utilities		Biomedical abstracts with pre-tagged drugs, genes and diseases.Literature evidence for the retrieval agent.W9Planned Free API with entity annotations, so no custom NER is needed.
Identifiers used for joining: compounds by InChIKey (not SMILES, whose text differs between databases); proteins by UniProt accession.
